# 诅咒特判汇总（1.2.0.1）

依据：`dlcs/dlc_1/dlc_1_data.gd` 的 `curse_item()`。图鉴实现：`main.py` 的 `_build_curse_types()`（数值）、`scaling_cursed()`（加成倍率是否放大）、`_build_cursed_extra_effects()`（诅咒附加效果）、`_get_cursed_text_key()`（诅咒换文本），前端 `applyCurse()`。

下文 `m` 为诅咒系数：`(40 + 2 × min(20, 波次-1) ± 随机 30) / 100`，即 0.1–1.1（图鉴滑条 10–110），「正向提高」= `ceil(|v| × (1+m))`（保留符号），「负向降低」= `max(1, floor(|v| / (1+m)))`。

## 通用规则

| 对象 | 行为 |
| --- | --- |
| 可否诅咒 | `ItemService.can_item_be_cursed`：只排除已诅咒、已机械化、已异变的物品。机械 / 异变 / 进化道具本身可以被诅咒 |
| 武器基础属性 | 伤害 ×(1+m) 向上取整；加成倍率 ×(1+m)；暴击伤害 ×(1+m/5)（保留 1 位）；生命窃取 ×(1+m)（>0 时）；穿透、弹跳 `min(原值+1, ceil(原值×(1+m/5)))`（>0 时） |
| 普通效果（`else` 分支） | 按效果符号：正面 → 正向提高；负面 → 负向降低；中性 → 不变 |
| 诅咒值 | 若效果里本身没有诅咒值，追加一行 `+round(max(1, 0.04 × 价格 × (1+m)))` 诅咒 |
| 一个物品多个效果 | 每个效果单独掷一次 `m`（图鉴统一用滑条值） |

**NullEffect 子类**（1.2 新武器效果多为此类）也落入普通分支：只提高隐藏的 `value` 字段。显示文本若不读 `value`，诅咒后**看不出变化**。

## 加成倍率（scaling）是否放大

放大：武器基础属性、投射物类效果（`ProjectileEffect` / `ProjectilesOnHitEffect`，含感染皮肤棘刺）、无生成冷却且有加成的建筑（炮塔等）、`SpawnStructureEveryKilledEnemiesEffect`（撬棍炮塔）、宠物（Bonk 狗、猫特林、布雷机器人、焰蜥蜴的燃烧加成、鼠斯拉、阿蚊、好饿好饿的小恐龙）、`ItemExplodingEffect`（非“按损失生命”型）、燃烧型建筑（只放大燃烧加成）。

**不放大**（图鉴在 `<scaling>` 上标 `fixed="1"`）：
- `BurningEffect` / `BurnChanceEffect`：只提高燃烧伤害与时长（火把、火球、喷火器、魔杖、烈焰黄铜指虎、粒子加速器、莫洛托夫的燃烧行、害怕的香肠……）
- 有生成冷却的建筑（地雷、螺丝刀、锥子 / 飞箭陷阱、花园……）：只缩短生成冷却
- 光剑反弹、莫洛托夫火焰池、岩浆靴火焰轨迹、纵火者两条火焰池、碳纤维弓各行

## 武器

| 武器 | 效果 | 诅咒行为 |
| --- | --- | --- |
| 光剑 | 反弹投射物（`DeflectProjectilesEffect`） | 显示不变 |
| 锥子 | 飞箭陷阱（建筑，spawn_cooldown>0） | 只缩短生成间隔：`int(max(2, 冷却/(1+m)))`；伤害、加成不变 |
| 撬棍 | 每击杀 N 敌人生成炮塔 | 炮塔伤害、加成提高；击杀数、易伤（%/持续/上限）不变 |
| 莫洛托夫鸡尾酒 | 火焰池 | 不变 |
| 莫洛托夫鸡尾酒 | 燃烧 | 燃烧伤害、时长提高；加成不变 |
| 麻醉步枪 | 范围减速 `[范围, 减速%, 时长]` | 只提高减速%（无上限显示） |
| 鞭子 | 命中减速 `[减速%, 时长]` | 只提高减速% |
| 缠手带 | 击退达到阈值时伤害翻倍 | 阈值（`value`）正向提高，即门槛变高（10→21） |
| 铲子 | 击杀挖箱几率，显示 `value/100` | `value` 正向提高后再 /100（50→105 → 0.5%→1.05%） |
| 粘性手雷 | 延迟爆炸 | 显示不变（延迟取 `fuse_duration`） |
| 碳纤维弓 | 减速 / 穿透 / 地雷行 | 只提高第一个数（减速%、穿透数、地雷几率）；持续时间、地雷伤害不变 |
| 碳纤维弓 | 燃烧行 | 不变（读 `burning_data`） |
| 带爆炸几率的武器（`ExplodingEffect`，几率<100%） | 爆炸几率 | `min(1, 几率×(1+m/5))`，到 100% 时换文本为「命中时爆炸」 |
| 每第 X 发投射物（武器 `WeaponEffectWithSubEffects`） | X | `max(1, X-1)`，按 1/2/3 换「第一 / 第二 / 第三」文本 |
| 钉锤（`weapon_mace`）攻速 | | 强制视为正面提高 |

## 图鉴未覆盖 / 近似处理

- 每个效果实际独立随机 `m`，图鉴统一用滑条值。
- 铲子、盗龙眼、和平主义者按小数直接相乘，未复刻「先对整数 value 向上取整再 /100」，误差 < 0.01。
- 锥子 / 飞箭陷阱的生成间隔用「负向降低」（最小 1），游戏最小 2；在滑条范围内结果相同。
- 蝾螈的追加属性依赖运行时最高 / 最低属性，未显示。
