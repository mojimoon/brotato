# 诅咒、异变与机械化机制（1.2.0.1）

依据反编译源码整理。主要文件：

- 诅咒（深渊恐惧 DLC，`abyssal_terrors`）：`dlcs/dlc_1/dlc_1_data.gd`（数值见 `dlc_data.tres`）、`effect_behaviors/scenes/curse_scene_effect_behavior.gd`、`effect_behaviors/enemies/curse_enemy_effect_behavior.gd`、`singletons/entity_service.gd`
- 进化 / 机械 / 异变（史前惧兽 DLC，`primal_dread`）：`dlcs/dlc_2/dlc_2_data.gd`（数值见 `dlc_2_data.tres`，**会覆盖脚本默认值**）、`global/team_evolution.gd`、`effect_behaviors/scenes/evolution_scene_effect_behavior.gd`、`effect_behaviors/enemies/{meca,mutant}_enemy_effect_behavior.gd`、`singletons/run_data.gd`（异变、拾取限制、精英）、`singletons/item_service.gd`（商店池、合成、风味）、`main.gd`（掉落）

单个道具被诅咒时每种效果怎么变，见 [curse-special-cases.md](curse-special-cases.md)。本文讲整体机制。

记号：`C` = 诅咒属性（取 `max(0, max(诅咒, curse_cap))`），`E` = 进化属性（正 = 机械，负 = 异变）。`f(v, 上限, 尺度) = 上限 × (1 − 1/(1 + v/尺度))` 是游戏里诅咒和进化共用的饱和曲线（`Utils.get_curse_factor` 的尺度固定为 50，`get_evolution_factor` 的尺度默认 50）。

## 一、诅咒

### 1. 诅咒值来源

| 来源 | 数值 |
| --- | --- |
| 被诅咒的物品 | 每件追加一行 `round(max(1, 0.04 × 物品价格 × (1+m)))` 诅咒（物品自带诅咒行时改为放大那一行），`m` 为该物品的诅咒系数 |
| 升级选项（诅咒属性） | `dlcs/dlc_1/upgrades/curse` |
| 道具 | 被腐蚀的碎片 +1、鱼钩 +1、黑旗 +5、克拉肯的眼睛 +15、藤壶（升级时 +1） |
| 海军套装 | 2/3/4/5/6 件：+1/+2/+3/+4/+5 |
| 角色 | 水手 +25；生物：升级时 +1；浪漫之人：每波结束 +1 |
| 击杀海猪 | 击杀者 +1（`sea_pig.gd`） |

### 2. 物品被诅咒的几率（商店 / 箱子）

商店的道具和武器、箱子里的物品、保底物品，生成时都会走 `ItemService.apply_item_effect_modifications` → `DLC1Data.update_item_effects`：

```
几率 = f(C, 15, 50) %      （base_item_curse_chance = 0，上限 max_curse_item_chance = 15%）
```

| C | 5 | 10 | 25 | 50 | 100 | 200 | 300 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 物品诅咒几率 | 1.4% | 2.5% | 5% | 7.5% | 10% | 12% | 12.9% |

不能被诅咒的物品：已诅咒、已机械化、已异变（`can_item_be_cursed`）。

其他产生诅咒物品的途径：

- **鱼钩**（`curse_locked_items` +20）：每次离开商店时，打乱锁定物品的顺序后逐个判定，每件的几率为 `(保底 + 20)%`。一旦诅咒成功，保底清零；如果一件都没被诅咒，`保底 += 没被诅咒的件数 × 20/4`。
- **生物**：开局获得 1 个被诅咒的鱼钩（`cursed_starting_item`，关闭随机，系数取第 1 波基准值 0.4）。
- **合成**：只要有一把是被诅咒的，合成结果就会重新诅咒，系数下限取两把中较大的 `curse_factor`。
- **弹药恐龙**：发射的武器按道具自身的系数诅咒（关闭随机）。
- **恐龙蛋**：被诅咒的蛋孵化出的下一阶段仍是被诅咒的（系数不变）。

### 3. 诅咒系数 m

```
m = (40 + 2 × min(20, 波次−1) + 随机[−30, 30]) / 100      → 第 1 波 0.1–0.7，第 21 波起 0.5–1.1
```

物品上的每个效果各掷一次 `m`，记录的 `curse_factor` 取其中最大值。效果放大 / 缩小规则见 [curse-special-cases.md](curse-special-cases.md)。

### 4. 敌人被诅咒

在敌人生成时判定（`CurseSceneEffectBehavior`）。**头目、精英**（`Boss` 类）、**搜刮者类**（loot alien）以及 `can_be_cursed = false` 的敌人不会被诅咒。

```
单人几率 = min(1, f(C, 100, 50)/100/2 × (1 + 无尽系数/2))
实际几率 = 所有玩家单人几率的平均
```

| C | 10 | 25 | 50 | 100 | 200 |
| --- | --- | --- | --- | --- | --- |
| 敌人诅咒几率（非无尽） | 8.3% | 16.7% | 25% | 33.3% | 40% |

被诅咒敌人的加成（`.tscn` 覆盖值：生命 150、伤害 25、速度 15）：

| 项 | 数值 |
| --- | --- |
| 生命 | `+150% + 2 × min(全队诅咒之和, 300)%`（C=10 → +170%；C=50 → +250%；上限 +750%） |
| 伤害 | +25% |
| 速度 | +15% |
| 材料 | 掉落 ×(1 + 0.33)（与其他效果行为的加成相加） |
| 外观 | 紫色描边 |

相关效果：

- 水手：海军武器对被诅咒敌人 +200% 伤害（`bonus_weapon_class_damage_against_cursed_enemies`）
- 黑旗：击杀被诅咒敌人 +1 材料（`gold_on_cursed_enemy_kill`；诅咒后换复数文本）

### 5. 诅咒对无尽模式的影响

仅在无尽模式中生效（`EntityService`，`avgC` = 全队平均诅咒，负数按 0）：

- 敌人伤害：`无尽系数 × (1 + √avgC / 25)`
- 敌人生命：`无尽系数 × 2.25 × (1 + √avgC / 10)`

另外，无尽模式中敌人的诅咒几率也会 ×(1 + 无尽系数/2)。

### 6. 随诅咒成长的效果

| 来源 | 效果 |
| --- | --- |
| 生物 | 武器和宠物伤害获得 35% 诅咒加成 |
| 浪漫之人 | 每 5 诅咒 −3% 伤害、−1 护甲 |
| 锚（Ⅱ/Ⅲ/Ⅳ） | 诅咒加成 75% / 100% / 125% |
| 船长的剑（Ⅲ/Ⅳ） | 诅咒加成 100% / 125% |
| 三叉戟（Ⅱ/Ⅲ/Ⅳ） | 诅咒加成 15% / 30% / 50% |
| 克拉肯的眼睛 | 受击时 50% 几率爆炸，诅咒加成 500% |

## 二、进化值 E（机械 / 异变的共同基础）

### 1. 来源

| 来源 | 数值 |
| --- | --- |
| 机械果 / 异变果 | +1 / −1 |
| 机械化武器 | 第一次机械化时武器上追加 +1 进化 |
| 异变物品 | 每次异变 −1（物品原本带进化行、且是第一次异变时 −2，见第四节） |
| 进化飞跃（机械） | 装备时进化 ×2，并 +2 |
| 进化飞跃（异变） | 装备时进化 ×2，并 −2 |
| 干扰背包 +5、邪神像 −5、强化有丝分裂 −3 | |
| 罐装剃须泡沫（机械 / 异变） | ±1 |
| 机械土豆 | 每波结束 +1 |
| 疯狂科学家 | 每波结束 +2 |
| 异种 | 每波结束时若无法异变：−1 |
| 升级选项（进化） | `items/upgrades/evolution` |

进化飞跃的效果顺序是先乘后加：`E' = 2E ± 2`。移除时按除法还原（`MultiplyValueEffect.unapply`）。

### 2. 阵营门槛与限制（`EVOLUTION_CAMP_LOCK_THRESHOLD = 2`）

| 内容 | 条件 |
| --- | --- |
| 商店出现机械物品 | `E > 2`（即 ≥ 3） |
| 商店出现异变物品 | `E < −2`；双向进化时 `E > 2` 也会出现 |
| 商店出现进化物品（塑料靴子） | `|E| > 2` |
| 可拾取机械果 | 不是只能异变，且 `E ≥ −2` |
| 可拾取异变果 | 不是只能机械化，且 `E ≤ 2` |
| 可拾取机械部件 | 只能机械化，或（不是只能异变且 `E > 0`）；双向进化时 `E ≠ 0` |
| 可拾取异变果实（mutation fruit） | 只能异变，或（不是只能机械化且 `E < 0`）；双向进化时 `E ≠ 0` |
| 能触发异变 | `E < 0`；双向进化时 `E ≠ 0` |

- 机械物品：进化飞跃（机械）、超量钛合金、干扰背包、生化臂、故障保险核心、罐装剃须泡沫（机械）
- 异变物品：进化飞跃（异变）、邪神像、强化有丝分裂、野火异变、罐装剃须泡沫（异变）
- 进化物品：塑料靴子
- 发焰筒、发热反应、病毒虽然带进化标签，但在普通物品池里

### 3. 角色规则

| 角色 | 规则 |
| --- | --- |
| 机械土豆 | 只能机械化（`meca_only`）：拾取异变果实不会累计异变次数；升级时 +1 机械部件；禁用的机械属性：最大生命、生命再生、生命窃取 |
| 异种 | 只能异变（`mutant_only`）；每波结束自动异变一次；50% 几率异变为更高品质的物品 |
| 疯狂科学家 | 双向进化（`dual_evolution`）：见第六节；异变果实掉率 +100% |

### 4. 进化果掉落（机械果 / 异变果）

只要 DLC 启用，击杀任何**未进化**的敌人都会判定（`main.gd spawn_evolution_fruit`），与当前进化值无关：

```
几率 = 2%（evolution_fruit_base_chance）
```

掉哪一种果（看击杀者）：只能机械化 → 机械果；只能异变 → 异变果；双向进化 → 随机；`E > 2` → 机械果；`E < −2` → 异变果；其他情况随机。

## 三、机械化（只针对武器）

### 1. 商店 / 箱子生成机械武器

`DLC2Data.update_item_effects` 只处理武器：

```
几率 = f(max(0, E), 81, 70) %      （tres 覆盖：基础 0，上限 81%，尺度 70）
```

| E | 1 | 3 | 5 | 10 | 20 | 30 | 50 | 70 | 100 | 150 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 机械武器几率 | 1.1% | 3.3% | 5.4% | 10.1% | 18% | 24.3% | 33.8% | 40.5% | 47.6% | 55.2% |

`E ≤ 0` 时不会生成。双向进化时进化值始终为正，所以照常生成。

### 2. 一次机械化做了什么（`meca_item`）

设当前机械等级为 `rank`（未机械化为 0），本次费用 `cost = rank + 1`：

1. **进化**：第一次机械化时，武器追加一行 +1 进化。
2. **机械部件计数**：武器上隐藏的计数行 += `cost`（第一次时新建，值为 `cost`）。回收或卖出武器时按这个计数**全额退还**机械部件。
3. **属性二选一**：从 4 个类别中随机挑 2 个不同类别，每个类别抽 1 个属性，玩家选一个，变成武器上的 `ModularEffect`（持有期间生效）。同一属性多次选择时数值叠加。
   - 防御：最大生命、护甲、闪避、生命再生、生命窃取
   - 辅助：速度、范围、幸运、收获
   - 伤害：%伤害、攻击速度、暴击率
   - 流派伤害：近战 / 远程 / 工程 / 元素伤害——**取玩家当前最高的那项**；并列时取武器上加成倍率最高的
   - 排除：角色的 `banned_meca_stats`；闪避已到上限时排除闪避；暴击率已到 `min(上限, 100)` 时排除暴击率；可选属性不足 2 个时取消所有排除
   - 数值 = 升级选项中「品质 `cost−1`」的数值；超过传说品质后按最后一档的差值线性外推

   | 属性 | cost 1 | 2 | 3 | 4 | 之后每级 |
   | --- | --- | --- | --- | --- | --- |
   | 最大生命 | 3 | 6 | 9 | 12 | +3 |
   | 护甲 | 1 | 2 | 3 | 4 | +1 |
   | 闪避 | 3 | 6 | 9 | 12 | +3 |
   | 生命再生 | 2 | 3 | 4 | 5 | +1 |
   | 生命窃取 | 1 | 2 | 3 | 4 | +1 |
   | 速度 | 3 | 6 | 9 | 12 | +3 |
   | 范围 | 15 | 30 | 45 | 60 | +15 |
   | 幸运 | 5 | 10 | 15 | 20 | +5 |
   | 收获 | 5 | 8 | 10 | 12 | +2 |
   | %伤害 | 5 | 8 | 12 | 16 | +4 |
   | 攻击速度 | 5 | 10 | 15 | 20 | +5 |
   | 暴击率 | 3 | 5 | 7 | 9 | +2 |
   | 近战伤害 | 2 | 4 | 6 | 8 | +2 |
   | 远程伤害 | 1 | 2 | 3 | 4 | +1 |
   | 工程 | 2 | 3 | 4 | 5 | +1 |
   | 元素伤害 | 1 | 2 | 3 | 4 | +1 |

4. **机械强度** `power += cost`，然后从原版武器的基础属性重新计算：
   - 伤害、加成倍率、生命窃取：×(1 + 0.05 × power)（伤害向上取整）
   - 暴击伤害：×(1 + 0.02 × power)
   - 远程武器：每 4 点 power +1 穿透；原本能弹跳的 +1 弹跳
   - 武器效果生成的建筑（`_boost_evolved_structure_effect`，`m = 0.05 × power`，冷却 `max(2, int(cd / (1 + m)))`，按顺序取第一条命中的分支）：
     1. 有生成冷却：缩短生成冷却（秒），并且伤害 / 加成按上面的规则强化 —— 锥子（飞镖陷阱）、螺丝刀（地雷）
     2. 有加成：伤害 / 加成强化 —— 扳手 Ⅰ/Ⅲ/Ⅳ 炮塔、撬棍（每击杀 X 个敌人生成的炮塔，击杀数不变）
     3. 无子效果：缩短建筑自身冷却（帧）—— 修枝剪（花园产果间隔）
     4. 第一个子效果是燃烧：只放大燃烧的加成，燃烧伤害与持续时间不变 —— 扳手 Ⅱ 火焰炮塔
     - 建筑不加穿透（弹跳仅原本 > 0 时 +1，现有建筑都没有）；碳纤维弓的地雷是 NullEffect，不受影响
5. `rank += 1`。

商店里生成的机械武器相当于已经机械化了一次：rank 1、power 1、计数 1、+1 进化，属性在购买时选择。

### 3. 在商店里机械化已有武器

武器弹窗中的「机械化（−X）」按钮：

- 费用：`rank + 1` 个机械部件（未机械化的武器为 1，之后 2、3、4……）
- 被诅咒的武器不能机械化（武器不会异变）
- 连续机械化 k 次后：power = 1+2+…+k，例如 3 次 → power 6 → 伤害 +30%、暴击伤害 +12%、+1 穿透

### 4. 机械部件

| 来源 | 数值 |
| --- | --- |
| 机械化敌人掉落的部件 | 每个 +2 |
| 拆卸商店里的机械武器 | 支付拆卸价格后 +1；该物品从商店移除 |
| 回收 / 卖出机械武器 | 按武器的计数全额退还 |
| 机械土豆 | 升级时 +1 |

- 机械部件掉落：只有机械化敌人死亡时判定。`几率 = min(1, 2% × 保底) / (1 + 0.5 × 本波已掉数量)`，`保底 = 1 + 连续未掉次数/20`（全队共用一个计数）。
- 拆卸价格：`get_value(波次, 11) × (1 + 拆卸价格%) × (1 − 回收收益%)`，至少 1。超量钛合金：拆卸价格 −25%。

### 5. 合成机械武器

- 结果仍是机械武器：机械部件计数相加、power 相加、rank 取较大者、两把武器选过的属性合并。
- 进化 +1 只保留一份：两把各带 +1 的机械武器合成后只剩 +1，即进化净减 1。

## 四、异变（只针对道具）

### 1. 何时异变

- 拾取异变果实：异变次数 +1（只能机械化时不累计）
- 异种：每波结束 +1 次
- 每波结束时，按累计次数逐次调用 `mutate_random_item`：
  - 需要满足 `E < 0`（双向进化时 `E ≠ 0`），且有可异变的道具
  - 不满足时：如果有「每波结束异变」效果（异种），改为进化 −1；否则这次异变作废
- 可异变的道具：不是诅咒或机械的道具（已异变的道具**可以再次异变**），并排除建造者炮塔、进化飞跃、肿瘤、美西螈。每次从中随机抽一件。角色本身（`CharacterData`）也在列表里

### 2. 一次异变做了什么（`mutant_item`）

1. **进化**：
   - 道具已有进化行（没有 custom key 的那种）时：第一次异变 −2，之后每次 −1
   - 没有进化行时：追加 −1
2. **50/50**：二者都可行时各 50%；只有一种可行时执行那一种；都不可行时追加「什么也没发生」标记。
   - **移除负面效果**：从这件道具上随机移除一个负面效果（记入 `mutation_removed_effects`）。不会移除的：进化行、空 key、开关类效果、`[EMPTY]` 文本的效果，以及下波属性、开局生命、额外敌人、近战 / 远程武器上限、武器品质上下限、武器栏、额外精英几率。角色本身不会被移除效果。
   - **复制正面效果**：从玩家持有的所有道具（含这件，不含肿瘤）中随机抽一个可复制的正面效果，按异变强度缩放后加到**肿瘤**道具上。没有肿瘤时会新建一个。相同效果会合并：数值相加，爆炸按期望伤害合并几率与伤害。
3. 标记 `is_mutant = true`。

**异变强度**：`scale = 0.1 + 0.9 × √(min(|E|/150, 1))`

| \|E\| | 1 | 5 | 10 | 20 | 30 | 50 | 67 | 100 | 150 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| scale | 0.17 | 0.26 | 0.33 | 0.43 | 0.50 | 0.62 | 0.70 | 0.84 | 1.00 |

复制时数值 `ceil(|v| × scale)`（保留符号）。几率类、燃烧伤害、爆炸几率与伤害等也一并缩放。不缩放的：燃烧中击杀得属性、区域内击杀得属性、转换奖励金币。

**不能复制的效果**：

- 非正面的效果、开关类效果、`NullEffect`、建造者炮塔类、乘值、属性转换
- 黑名单：复制道具、沙漏、各种价格、持续回复、刷新提升品质、下波属性、生命 / 闪避上限、异变果实几率、生命形态扫描仪、开局物品 / 武器、经验需求、商店最少武器、治疗时造成伤害、保底商店物品、武器栏升级、更强的搜刮者 / 精英、偷窃、特定物品价格、火焰爆炸、受击时减速时间、只能异变、每波异变、商店不出武器
- 状态已饱和的：爆炸几率已达 100%（可叠加的爆炸看总和）、水母盾已有 3 个、移除速度已到上限、穿透 / 弹跳伤害已抵消衰减、全局燃烧几率已达 100%、部分几率类已达 100%、非噩梦难度下的迷雾视野、100% 吸金
- 生成实体的效果（建筑、宠物）需要 `scale ≥ 0.7`（`|E| ≳ 67`），恐龙蛋永远不能复制；部分效果也需要 `scale ≥ 0.7`（药水回复加成、每件带某属性的道具得属性、燃烧 / 区域击杀得属性、满血吃果得属性、转换奖励金币、更高品质异变、死亡投射物、挖掘点）

### 3. 异变为更高品质（野火异变 +25%、异种 +50%）

条件：道具品质 < 传说，且这件道具还没有异变过。判定成功时，换成高一档品质的随机道具（优先选择有共同标签的），再对新道具执行异变。替换后原道具的属性上限不会恢复。

### 4. 异变果实掉落（mutation fruit）

只有异变敌人死亡时判定，且至少一名玩家持有 ≥ 3 件可异变的道具（不算角色本身）：

```
几率 = min(1, 3% × 保底 × (1 + 掉率加成%)) / (1 + 0.5 × 本波已掉数量)
保底 = 1 + 连续未掉次数/20
```

掉率加成为全队之和：强化有丝分裂 +50%、疯狂科学家 +100%。

## 五、进化敌人（机械化 / 异变敌人）

### 1. 几率（`TeamEvolution`）

```
加权 = |E × (1 + 敌人进化几率%)|
单人几率 = min(1, f(加权, 100, 50)/100/2 × (1 + 无尽系数/2))
精英几率 = min(1, 单人几率 × 4)
实际几率 = 全队平均
```

| \|E\|（无加成） | 1 | 3 | 5 | 10 | 20 | 30 | 50 | 100 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 普通敌人 / 头目 | 1% | 2.8% | 4.5% | 8.3% | 14.3% | 18.8% | 25% | 33.3% |
| 精英 | 3.9% | 11.3% | 18.2% | 33.3% | 57.1% | 75% | 100% | 100% |

罐装剃须泡沫：敌人进化几率 +50（即加权 ×1.5）。

**阵营**：按权重抽取。机械权重 = 正 E 之和，异变权重 = 负 E 绝对值之和；双向进化的玩家两边各计 |E|。全队都是 E = 0 时没有任何敌人会进化。**强度 M** = 该阵营玩家 |E| 的平均值。

### 2. 判定对象

- 普通敌人：生成时按普通几率判定
- 头目（非精英）：同样按普通几率判定
- 精英：每个精英波开始时用精英几率掷一次，成功时把该波精英换成该区域的机械 / 异变精英变种。只有存在进化精英的区域才会这样
- 本身就是机械 / 异变的敌人（场景预设、进化精英），以及腕龙的脚（跟随腕龙本体）：直接按对应阵营套用加成
- 搜刮者类（loot alien）不会进化

## 六、双向进化（疯狂科学家）

- 所有进化变化在**应用时取绝对值**（`Effect.get_applied_value`）：异变果、异变道具的 −1、邪神像 −5 等都变成增加。进化值只增不减，始终 ≥ 0
- 商店：`E > 2` 时机械物品和异变物品同时出现
- 机械武器：照常生成（E 为正）
- 异变：`E ≠ 0` 即可触发；可拾取机械部件和异变果实
- 进化果：随机掉机械果或异变果，两种都能拾取
- 敌人：机械和异变权重各计 |E|，所以两种各占一半
- 进化文本：颜色统一显示为有利色，不再区分蓝 / 黄（`Effect.get_evolution_sign`）；属性面板显示 `INFO_DUAL_STAT_EVOLUTION`

## 七、共存与互斥

### 1. 物品风味互斥

一件物品只能是 **普通 / 诅咒 / 机械 / 异变** 中的一种（`get_flavor`，判定顺序诅咒 > 机械 > 异变）：

| 操作 | 不允许的对象 |
| --- | --- |
| 诅咒 | 已诅咒、机械、异变 |
| 机械化 | 非武器、诅咒、异变 |
| 异变 | 诅咒、机械（以及第四节中排除的道具）；**已异变的可以再异变** |

- 武器永远不会异变（异变只会从道具列表中抽）
- 道具永远不会被机械化（只有武器）
- 诅咒、机械、异变的物品在背包里不会和普通物品叠放

### 2. 同时启用两个 DLC 时的生成顺序

`apply_item_effect_modifications`：

- 默认先判定机械化，再判定诅咒；当**原始进化值 < 原始诅咒值**时，改为先判定诅咒
- 任意一步成功（变成机械或诅咒）后就不再判定下一步
- 结果：武器按顺序各掷一次，先成功的那个生效；道具只会掷诅咒。由于两次判定互相独立，后判定的那一个实际几率会被前一个吃掉一部分

### 3. 合成

- 风味兼容：普通能与任意风味合成；同风味之间可以合成；**诅咒与机械不能合成**
- 结果的风味取第一个非普通的那个：诅咒 → 重新诅咒（系数下限取两者较大值），机械 → 见第三节第 5 小节
- 选择合成对象时的优先级（`get_combine_candidates`）：风味不同但兼容的（普通配有风味的）+2，与「偏好风味」相同的 +1。偏好风味：`|E| > C` 时取机械 / 异变（双向进化时随机），否则取诅咒

### 4. 敌人：诅咒与进化可以叠加

敌人生成时依次执行 `scene_effect_behaviors = [诅咒, 进化, 挖掘点, 偷猎区]`：

1. 先判定诅咒。被诅咒的敌人会获得诅咒加成，并设置 `can_be_boosted = false`
2. 再判定进化。成功时 `enemy.boost()` 会因为 `can_be_boosted = false` 直接返回，**不会再获得进化的生命 / 伤害 / 速度加成**，但仍然会被标记为机械 / 异变，换贴图与描边，并添加对应的效果行为

所以一个敌人可以同时是「被诅咒 + 机械 / 异变」：

- 只拿诅咒的属性加成
- 材料 ×(1 + 0.33 + 0.33)
- 会掉机械部件 / 异变果实，会留地面池，也吃发焰筒、发热反应、病毒、干扰背包等效果
- 不再掉机械果 / 异变果

头目和精英不会被诅咒，只能进化。

### 5. 诅咒值与进化值彼此独立

两者没有直接换算。互相影响的只有：

- 物品生成时的判定顺序（第 2 小节）
- 合成时的偏好风味（第 3 小节）
